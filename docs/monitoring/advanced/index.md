## When to use advanced features

### Multi-cluster monitoring

Use when:
- Managing more than 3-5 PostgreSQL clusters
- Need unified view across environments
- Want centralized alerting

## Prerequisites

Advanced topics assume familiarity with:
- Basic PostgresAI monitoring setup
- Prometheus/PromQL queries
- Docker Compose or Kubernetes
- PostgreSQL administration
