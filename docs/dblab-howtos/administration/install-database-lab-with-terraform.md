Terraform is no longer a supported method for installing DBLab Engine. Instead, install DBLab using [the PostgresAI Console](/docs/dblab-howtos/administration/install-dle-from-postgres-ai) or [the AWS Marketplace](/docs/dblab-howtos/administration/install-dle-from-aws-marketplace).
